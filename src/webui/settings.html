复制处理

复制超过尺寸上限的静态图时按此处模式处理；动图不受影响。隐写模式会把原图信息随 GIF 隐藏，接收方可运行解码工具还原，但会显著增大文件体积。

聊天客户端适配

普通点击表情始终只复制。选择 QQ 或微信后，请在目标聊天窗口前台按全局快捷键呼出本程序；只有右键明确选择「复制并粘贴」时才会尝试 Ctrl+V。不会读取聊天记录、监听剪贴板、按 Enter 或点击发送按钮。

存储位置

表情包图片文件存放目录；数据库与缩略图仍保留在系统数据目录

从手机导入

通过 ADB 从连接的 Android 手机拉取 QQ 表情包缓存并打包 ZIP

从电脑导入

从 PC 版 QQ（QQNT）本地缓存批量提取收藏表情

从 Telegram 导入

从 Telegram Desktop 本地缓存解密提取表情包（WebP 直取，WebM 无损转 WebP 并保留透明通道）

从抖音导入

通过抖音网页版 API 下载自定义表情包（WebP 原格式保存，需登录 Cookie）

从微信导入

从微信电脑版本地缓存提取收藏表情（需微信正在运行，仅 Windows 支持）。微信文件目录是存放所有账号数据的根目录（xwechat_files），其下的 wxid_* 文件夹为各账号目录

局域网互联

与手机版 OhMyMeme 在同一局域网内配对，互相同步表情包与配置
