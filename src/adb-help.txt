国内主流手机开启ADB（USB调试）步骤汇总
通用底层逻辑：连续点击版本号7次激活开发者选项 → 打开USB调试 → 数据线连接电脑，弹窗授权

重要提醒：
1. 尽量使用数据传输线，仅充电线无法识别ADB；USB模式选择【文件传输/MTP】
2. 首次连接手机会弹出「允许USB调试」，勾选始终允许此计算机，点击允许
3. Android11+ 自带【无线调试】，可免数据线连接；
4. 部分机型有厂商专属额外开关，漏开极易出现 unauthorized、找不到设备。

一、小米 / Redmi（HyperOS / MIUI）
1. 设置 → 我的设备 → 全部参数
2. 连续点击 HyperOS版本 / MIUI版本 7次，提示「已处于开发者模式」
3. 返回：设置 → 更多设置 → 开发者选项
4. ✅ 开启 USB调试
5. ✅【必开】USB调试（安全设置）（缺少此开关大量命令被拦截）
6. 可选开启：USB安装、无线调试

常见坑：必须登录小米账号才能打开「USB调试（安全设置）」

二、华为 / 荣耀（鸿蒙HarmonyOS / MagicOS）
鸿蒙OS 3/4
1. 设置 → 关于手机 → 连续点击 HarmonyOS版本7次
2. 设置 → 系统和更新 → 开发人员选项
3. ✅ USB调试
4. ✅【推荐开启】仅充电模式下允许ADB调试

鸿蒙OS 5.0+
暂未兼容HDC（HarmonyOS Debugging Command）

限制：隐私空间、子用户下无法开启开发者选项，需要切回机主空间

三、OPPO / 一加 / realme（ColorOS / Realme UI）
1. 设置 → 关于本机 → 版本信息
2. 连续点击 版本号7次
3. 设置 → 系统与更新 → 开发者选项
4. ✅ USB调试
5. 可选：USB安装、无线调试

踩坑：部分新版本ColorOS默认开启权限监控，会拦截ADB高级指令

四、vivo / iQOO（OriginOS）
1. 设置 → 我的设备 → 关于手机 → 版本信息
2. 连续点击 软件版本号7次
3. 设置 → 系统管理 → 开发者选项
4. ✅ USB调试
5. 需要自动化点击指令时：额外开启 USB模拟点击

五、魅族（Flyme）
1. 设置 → 关于手机 → 连续点击 版本号7次
2. 设置 → 辅助功能 → 开发者选项
3. ✅ USB调试、USB安装

老Flyme备用入口：拨号输入 *#*#6961#*#* 调出开发者入口

六、努比亚（MyOS）
1. 设置 → 关于本机 → 连续点击版本号7次
2. 设置 → 系统和更新 → 开发者选项
3. ✅ USB调试
4. ✅ 仅充电模式下允许ADB调试、USB安装

七、联想拯救者 / ZUI
1. 设置 → 关于本机 → 连续点击 ZUI版本7次
2. 设置 → 系统和更新 → 开发者选项
3. ✅ USB调试

通用排错清单（90%连接失败问题）
1. 执行 adb devices 空白
- 换原装数据线、电脑后置USB口
- 手机USB用途切换为【文件传输】，不要仅充电

2. 显示 unauthorized
- 拔掉重插，等待手机弹窗授权；开发者选项 → 撤销USB调试授权重试

3. 能识别设备，但很多命令执行失败
- 检查厂商专属安全开关（小米USB调试(安全设置)、华为仅充电ADB等）
