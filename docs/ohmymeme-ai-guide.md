# Ohmymeme-AI 增强版使用指南

本分支是 OhMyMeme 桌面端的增强版，重点增加本地文件夹管理、审核式 AI 整理、批量操作、拖拽优化和桌面/Android 分享包互通。

## 一、Windows 运行

### 便携版

运行 `OhMyMeme.exe` 即可启动。便携版必须保留以下结构，不能只复制 exe：

```text
OhMyMeme/
├── OhMyMeme.exe
└── _internal/
```

`_internal` 是程序运行依赖目录，丢失后程序可能无法启动。

### 源码运行

环境要求：Python 3.10+、Node.js 20+。

```bash
pip install -r requirements.txt
npm install
npx vite build
python -m src
```

## 二、文件夹与移动

主界面使用单层文件夹卡片，点击文件夹进入。

- **复制进去**：保留表情原有文件夹归属，同时增加目标文件夹归属。
- **移动进去**：按剪切语义处理，移除表情原有文件夹归属，只保留目标文件夹归属。
- 两种操作都会自动给表情添加目标文件夹同名标签。
- 根目录显示“未归档表情”，已经移动进文件夹的表情不会继续出现在根目录。
- 删除文件夹只解除文件夹归属，不删除图片、表情记录或标签。

可以通过拖拽、右键菜单或批量操作完成复制/移动。

## 三、批量操作

打开批量模式后：

- 单击表情、文件夹或标签即可选择；
- 可以全选当前页，也可以取消全选；
- 多选表情可以一起拖入收藏夹；
- 可以批量改标签、复制到文件夹、移动到文件夹、删除或导出分享包。

批量移动使用后端原子事务处理，避免部分成功或归属残留。

## 四、拖拽

- 表情可以拖到文件夹卡片；
- 拖到收藏夹可以收藏；
- 排序模式下可以拖动调整顺序；
- 指针靠近表情区域顶部或底部时会自动滚动，可以把底部表情拖到顶部文件夹或跨视口排序；
- 搜索或标签筛选状态下，拖出到外部应用会走原生文件拖拽。

## 五、AI 整理

AI 整理不会直接修改图库，流程固定为：

```text
生成建议 → 人工审核 → 确认应用
```

在设置页分别配置：

- AI 整理服务 Base URL、API Key、模型；
- AI 生图服务 Base URL、API Key、模型；
- 每轮审核数量，范围为 1–500。

审核时可以调整标签、文件夹、描述和 OCR 文本。只有点击确认应用后，修改才会写入本地数据库。AI 请求可能产生服务商费用，也可能将图片发送给你配置的服务商。

## 六、分享包

`.ohmymeme-pack` 是桌面端和 Android 端通用的 ZIP 分享包，包含：

- 图片；
- 原始名称；
- 标签；
- 收藏状态；
- 文件夹归属；
- 排序信息。

分享包不包含 API Key、同步密码、设置或本地路径。

桌面端：

- 导入菜单 → 导入 OhMyMeme 分享包；
- 更多菜单 → 导出当前列表；
- 批量选择后 → 导出分享包。

Android 端：

- 导入菜单可以导入 `.ohmymeme-pack`；
- 更多菜单可以导出全部表情；
- 单张表情菜单可以导出当前表情。

## 七、Android 版本说明

Android 源码位于本分支的 `android/` 目录。Android 版支持导入、搜索、文件夹、AI、分享包、云端同步和局域网互联等功能。

> **重要：安卓版悬浮窗功能仍在开发中，当前属于不完全版。** 如果悬浮窗在你的设备上可以正常使用，可以按需使用；如果无法使用，请直接忽略悬浮窗，不影响其他功能。遇到 Bug 请联系：<https://luckywszl.top>。
>
> **项目说明：本人并不擅长 Android 等移动端软件开发。** 如果有熟悉 Android 开发的开发者愿意接替或继续维护这个项目，欢迎基于本项目继续开发、修复和完善。

构建 Debug APK：

```bash
cd android
./gradlew :app:assembleDebug
```

APK 输出位置：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Android 构建需要 Android Studio、JDK 17+、Android SDK 36。安装 APK 时请根据系统提示允许安装未知来源应用。

## 八、安全与限制

- Ohmymeme-AI 不会自动发送 QQ/微信消息；
- 桌面端受控粘贴必须由用户明确选择“复制并粘贴”；
- Android 悬浮窗、无障碍、Shizuku、Root 等能力受设备和系统限制；
- 不要把 API Key、同步密码、`keystore.properties` 或 `.jks` 文件提交到 GitHub；
- 分享包导入前会检查路径、数量、大小、扩展名和图片内容。
